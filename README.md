## Current Projects

### 🏛️ AISSA Monorepo — [AI-Safety-SA/aissa-mono](https://github.com/AI-Safety-SA/aissa-mono)
A Turborepo-powered monorepo for AI Safety South Africa. Home to two apps:
- **Track Record** — a transparent impact dashboard for funders, showing AISSA's community reach and outcomes. Built on Next.js 15, Payload CMS 3.x, and PostgreSQL. Actively shipping features.
- **Website** — the public-facing AISSA site in Astro 5.x.

### 🔩 Gyre — An Autonomous Coding Agent Loop
A system of small, sharp tools that let AI coding agents run autonomously against a real codebase:

- 🛗 **[drydock](https://github.com/cyberCharl/drydock)** — Workbench and state store for the loop. Tracks work items, agent runs, and audit trails. Postgres + Hono + Drizzle + Rust CLI.
- 🐕 **[dogwatch](https://github.com/cyberCharl/dogwatch)** — CI/review monitor. Watches open PRs, correlates to Drydock work items, nudges coding agents on failures, and notifies when PRs are ready for human review. Written in Rust.
- 🚢 **[slipway](https://github.com/cyberCharl/slipway)** — Agent dispatch layer. *(In progress)*

## On the Side

- 🌊 **[dawn-patrol](https://github.com/cyberCharl/dawn-patrol)** — Multi-spot surf forecast aggregator with evening notifications. Cape Town specific. Bun + Hono + Drizzle + shadcn.
- 🔍 **[trawl](https://github.com/cyberCharl/trawl)** — Self-hosted personal capture and retrieval. Captures URLs, generates summaries, embeddings, and tags. Bun + Hono + SQLite + sqlite-vec semantic search.
- 🔗 **[obsidian-task-bridge](https://github.com/cyberCharl/obsidian-task-bridge)** — Obsidian plugin that exposes the Tasks plugin as a local REST API. Lets AI agents query and manage tasks over plain HTTP.
- 🍽️ **[table-for-two](https://github.com/cyberCharl/table-for-two)** — Weekly dinner specials tracker for Cape Town. Scrapes restaurants, browsable UI, visit history. Vite + React 19 + Tailwind v4 + SQLite.

- 🤖 **[multi-agent-reputation-system-simulation](https://github.com/cyberCharl/mutli-agent-reputation-system-simulation)** — Simulation of a multi-agent reputation system. Exploring accountability in decentralised agent networks.
